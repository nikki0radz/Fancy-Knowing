# Fancy Knowing bulb logo

Original generated bulb inspired by the user's supplied visual reference. Created with the built-in image-generation tool, then converted losslessly to WebP for the header/navigation and exported at browser/app-icon sizes. Transparency is preserved.

Prompt brief: an isolated mustard-gold light bulb, looping white filament, two dark navy rounded base bands, transparent background; no head, gears, arrows, decorations or text.

- `fancy-knowing-bulb.webp`: full-size transparent mark.
- `favicon.png`: 64px browser icon.
- `app-icon.png`: 512px icon asset for the app.
